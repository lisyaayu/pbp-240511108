# Bagian 2 — Analisis Komparatif Platform

## Tabel Komparasi Platform (Web vs Desktop vs Mobile)

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Bahasa utama** | HTML, CSS, JavaScript (TypeScript) | C#, C++, Python, JavaScript (Electron) | Swift (iOS), Kotlin/Java (Android), Dart (Flutter)[cite: 1] |
| **Arsitektur** | Client-Server (Browser-based, SPA/MPA)[cite: 1] | Native Application / Monolithic / Framework-based[cite: 1] | Native Application / Cross-platform (MVVM, BLoC)[cite: 1] |
| **Cara distribusi** | Melalui Web Hosting / URL (Akses via Browser)[cite: 1] | Installer khusus (`.exe`, `.msi`, `.dmg`, `.deb`) / App Store[cite: 1] | Google Play Store, Apple App Store, APK Sideloading[cite: 1] |
| **Keunggulan** | • Tidak perlu instalasi (cukup akses link)<br>• Mudah di-*update* secara *real-time*<br>• Kompatibel lintas platform[cite: 1] | • Performa tinggi dan akses penuh ke hardware PC<br>• Dapat berjalan *offline* dengan optimal<br>• Nyaman untuk pekerjaan kompleks[cite: 1] | • Mobilitas tinggi (selalu dibawa pengguna)<br>• Integrasi mendalam dengan sensor HP (GPS, Kamera, Sensor Gerak)<br>• Notifikasi *push* langsung[cite: 1] |
| **Keterbatasan** | • Ketergantungan penuh pada koneksi internet<br>• Akses terbatas ke perangkat keras lokal (hardware)<br>• Performa bergantung pada browser[cite: 1] | • Ukuran file instalasi besar<br>• Distribusi *update* harus diunduh manual oleh pengguna<br>• Terikat pada sistem operasi tertentu[cite: 1] | • Layar terbatas<br>• Kapasitas baterai dan memori perangkat terbatas<br>• Proses peninjauan (*review*) aplikasi di store yang ketat[cite: 1] |
| **Contoh aplikasi** | Google Docs, Netflix, Trello Web[cite: 1] | Microsoft Office, Visual Studio Code, VLC Player[cite: 1] | WhatsApp, Instagram, Mobile Legends[cite: 1] |

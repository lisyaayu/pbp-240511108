## Bagian 3 — Refleksi

1. **Platform yang Paling Menarik untuk Dipelajari**
   Bagi saya, platform **Mobile** adalah yang paling menarik untuk dipelajari. Hal ini dikarenakan aplikasi mobile memiliki portabilitas tinggi dan fleksibilitas integrasi dengan berbagai sensor perangkat secara langsung, seperti GPS, kamera, dan notifikasi *push*. Selain itu, pengembangan aplikasi mobile modern menggunakan *cross-platform framework* seperti Flutter/Dart atau Kotlin memungkinkan pembuatan aplikasi yang responsif, interaktif, dan berdampak langsung pada aktivitas harian pengguna.

2. **Tantangan Terbesar Saat Setup Environment**
   Tantangan terbesar yang saya hadapi saat *setup environment* adalah memastikan kecocokan (*compatibility*) antara arsitektur sistem (seperti perbedaan x64 dan ARM64), pengaturan variabel lingkungan (*Environment Variables / PATH*), serta ukuran unduhan software pendukung seperti Android SDK yang cukup besar dan membutuhkan koneksi internet yang stabil. Ketidaksesuaian alur konfigurasi sering kali menyebabkan perintah tidak dikenali di terminal/CMD.

3. **Rencana Mengatasi Tantangan**
   Untuk mengatasi tantangan tersebut, rencana saya adalah:
   - Membaca dan mengikuti dokumentasi resmi (*official documentation*) dari setiap tools dengan cermat sebelum melakukan instalasi.
   - Menggunakan terminal berbasis Bash (seperti Git Bash) untuk membiasakan diri dengan perintah standar industri software.
   - Melakukan verifikasi rutin di terminal menggunakan perintah versi (seperti `node -v` dan `java -version`) serta berdiskusi aktif dengan forum komunitas atau dosen jika menemui kendala *debugging* lingkungan pengembangan.
